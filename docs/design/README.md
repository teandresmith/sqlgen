# Design notes

These are internal design records, not user documentation. Each one holds the rationale and code-generation detail behind a feature as it was designed. The [PRD](../PRD.md) is the specification: where a note and the PRD disagree, the PRD wins. Notes in `archive/` describe finished work whose design the PRD now covers in full.

To use sqlgen, start with:

- [README](../../README.md): what sqlgen generates and how to get started
- [Configuration](../configuration.md): the full `sqlgen.yml` reference
- [`sqlgen manifest` CLI](../cli-manifest.md): manifest validate and diff tooling
- [PRD](../PRD.md): the full specification, for exact behavior
