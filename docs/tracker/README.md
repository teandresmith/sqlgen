# Implementation tracker

These are internal development records, not user documentation. They track how sqlgen was built: the phase plan, each phase's sub-items, fixes found during testing, and a backlog. The maintainers' Claude Code commands in `.claude/commands/` read and update them. Nothing here describes how to use sqlgen, and none of it needs reading to contribute.

To use sqlgen, start with:

- [README](../../README.md): what sqlgen generates and how to get started
- [Configuration](../configuration.md): the full `sqlgen.yml` reference
- [`sqlgen manifest` CLI](../cli-manifest.md): manifest validate and diff tooling
- [PRD](../PRD.md): the full specification, for exact behavior
